First public release of Relay for Android, with the same features as the iPhone app.

- QR code pairing with a Relay server (Administration → Devices); token encrypted by the Android Keystore.
- SSH, RDP, VNC sessions and Proxmox consoles in the app: touchpad or direct touch, pinch to zoom,
  keyboard bar (Esc, Ctrl, Alt, arrows, F1–F12), hardware keyboard, clipboard, several sessions kept alive in the background.
- Files over SFTP (SSH) and the "Relay" drive (RDP).
- Availability, vault with fingerprint/face unlock and TOTP, SSH commands on several servers, recordings player,
  workspaces, quick connect, activity log.
- Editing of entries, folders, vault and attachments; sync sources, duplicates, RDM import, encrypted backup.

Requires Android 8.0 or later and a Relay server with device tokens (Administration → Devices).

Première version publique de Relay pour Android, avec les mêmes fonctions que l'app iPhone.

- Appairage par QR code avec un serveur Relay (Administration → Appareils) ; jeton chiffré par le Keystore Android.
- Sessions SSH, RDP, VNC et consoles Proxmox dans l'app : pavé tactile ou toucher direct, pincer pour zoomer,
  barre de touches (Échap, Ctrl, Alt, flèches, F1–F12), clavier physique, presse-papiers, plusieurs sessions maintenues en arrière-plan.
- Fichiers en SFTP (SSH) et lecteur « Relay » (RDP).
- Disponibilité, coffre avec empreinte ou visage et TOTP, commandes SSH sur plusieurs serveurs, lecteur d'enregistrements,
  espaces de travail, connexion rapide, journal.
- Édition des entrées, dossiers, coffre et pièces jointes ; sources de synchro, doublons, import RDM, sauvegarde chiffrée.

Android 8.0 minimum et un serveur Relay avec jetons d'appareil (Administration → Appareils).
