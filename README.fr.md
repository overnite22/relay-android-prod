# Relay for Android

Application Android native (Kotlin, Jetpack Compose) pour [Relay](https://github.com/overnite22/relay-server-prod), le gestionnaire de connexions à distance auto-hébergé : inventaire, coffre d'identifiants, consoles SSH, RDP et Proxmox, appairée à votre serveur par QR code.

Ce dépôt reçoit les versions publiées. La première version est en préparation.
